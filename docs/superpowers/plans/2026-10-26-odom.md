# odom (wheel-odometry integration and residuals) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fill in `mss::odom::WheelIntegrator` (exact SE(2) integration of wheel samples into a body-frame `OdomDelta` with first-order covariance) and add the core-type residuals that O-01/O-02 test: the relative-pose residual against the odometry delta and the non-holonomic velocity residual, with analytic Jacobians.

**Architecture:** `WheelIntegrator` accumulates the pose of the odometry frame `o` on SE(2) (`x, y, yaw`) plus a 3x3 covariance in the SE(2) right tangent `[rho_x, rho_y, phi_z]`; `take_delta()` embeds both in SE(3) (tangent indices 0, 1, 5) and conjugates by `T_b_o`. A new additive header `mss/odom/odom_residual.hpp` holds two free functions that return residual + Jacobians in core types; `backend` later wraps them in GTSAM factors. No GTSAM and no Sophus in `odom`; Lie operations come from `mss/common/lie.hpp`.

**Tech Stack:** C++17, Eigen 3.4 (fixed-size only), GoogleTest, CMake (`mss_add_test`), WSL build via `tools/wsl/build.sh`.

**Spec:**

## Contract issues

1. **O-01 and O-02 test residuals that no frozen header declares.** `wheel_integrator.hpp` only produces `OdomDelta`; `graph.hpp` says the non-holonomic factor "is designed by the odom/backend modules". Proposed (additive, no existing signature changes): new public header `core/odom/include/mss/odom/odom_residual.hpp` with `relative_pose_residual(...)` and `nonholonomic_residual(...)` (Task 4 Interfaces). Needs the controller's agreement; the PR notes it.
2. **No sigma for the non-holonomic residual in config.** `WheelOdomConfig` has no lateral/vertical velocity sigma. Odom returns the residual unwhitened, so Phase 1 odom does not need one; the backend factor will. Proposed: `wheel_odom.nonholonomic_sigma_mps` (m/s, `> 0`) in `WheelOdomConfig`, `config/default.yaml` and `pipeline/src/config.cpp`, added together with the backend factor.
3. **SE(3) right-Jacobian inverse is missing from `mss/common/lie.hpp`.** The relative-pose Jacobians need `Jr(xi)^-1` on SE(3); only SO(3) `so3_jr_inv` exists and only `common` may include Sophus. Plan: a private closed form in `core/odom/src/odom_residual.cpp` (Task 4), verified by the Jacobian numerical test. Proposed: `common::se3_jr_inv(const Vec6&)` (Sophus `SE3d::leftJacobianInverse(-xi)`) in `common`; odom switches to it afterwards.
4. **Private members must be added to the frozen header.** `WheelIntegrator` declares no data members. Task 2 adds private members only (additive, allowed).

## Review Focus

1. **Pure rotation in place** (`v = 0`, `omega != 0`): translation stays exactly zero, yaw variance is `sigma_omega^2 * sum(dt^2)`, the `rho`-`phi` cross terms are exactly zero, and speed noise still enters the `rho` block (a zero reading is uncertain too). Test `WheelIntegrator.PureRotationInPlace` (Task 3).
2. **Reverse driving** (`v < 0`): a straight line gives `p.x = v * T < 0`; covariance equals the `|v|` case except the `rho_y`-`phi_z` cross term, which changes sign. Test `WheelIntegrator.ReverseDrivingStraight` (Task 3).
3. **Yaw increment near the small-angle series threshold** (`|omega * dt|` just below/above `kSeriesAngleRad`, `omega = 1e-12`, `omega = 0`): pose matches the analytic arc to `1e-12` on both sides, no NaN. Test `WheelIntegrator.SeriesThresholdContinuity` (Task 2).
4. **More than one full turn between keyframes** (accumulated yaw > 2 pi): `T_b0_b1` matches the analytic circle. Test `WheelIntegrator.MultiTurnWraps` (Task 2).
5. **Long gap between samples** (2 s dropout; no YAML key limits it): the next sample's reading is held over the whole gap as the header specifies; position advances `v * gap`, covariance grows with `dt^2`. Test `WheelIntegrator.LongGapHeldReading` (Task 3).

- [x] **Step 1: Write `docs/derivations/wheel_odom.md`** with these `##` sections (content fixed here; prose is the writer's):
  1. *Model.* Frame `o` (x forward, z up). Sample `k >= 1` uses its own `(v_k, omega_k)` over `dt_k = seconds_between(t_{k-1}, t_k)`: `s_k = v_k dt_k`, `a_k = omega_k dt_k`. Exact SE(2) increment `Delta_k = (R(a_k), t_k)`, `t_k = s_k [sin a / a, (1 - cos a) / a]`. Accumulate `T_o0_ok = T_o0_ok-1 * Delta_k`. For `|a| < kSeriesAngleRad = 1e-4` rad use `sin a / a ~ 1 - a^2/6`, `(1 - cos a)/a ~ a/2 - a^3/24` (planner's call; truncation `< 1e-18`).
  2. *Embedding and frame change.* SE(2) pose -> SE(3) with `z = roll = pitch = 0`; `T_b0_b1 = T_b_o * T_o0_o1 * T_b_o^-1`.
  3. *Covariance.* SE(2) right tangent `[rho_x, rho_y, phi_z]` = SE(3) tangent indices `0, 1, 5` to first order. Noise `n_k = [delta_s, delta_a]`, `Q_k = diag(sigma_v^2, sigma_omega^2) * dt_k^2` (header). `P_k = A_k P_{k-1} A_k^T + B_k Q_k B_k^T`, `A_k = Ad_SE2(Delta_k^-1)` with `Ad_SE2(R, t) = [R, [t_y; -t_x]; 0, 1]`; `B_k = [R(a)^T * dt/d(s, a); 0 1]`, `dt/ds = [sin a / a, (1 - cos a)/a]`, `dt/da = s [(a cos a - sin a)/a^2, (a sin a - 1 + cos a)/a^2]`, series `s [-a/3 + a^3/30, 1/2 - a^2/8]`. Embed `P` in a 6x6 `cov_o` (rows/cols 2, 3, 4 zero) and `cov = transform_covariance(cov_o, T_b_o)`, derived from `T_b_o T Exp(xi) T_b_o^-1 = T_b0_b1 Exp(Ad(T_b_o) xi)`. Systematic calibration error and slip (ADR-011 section 3) are not modelled; the YAML sigmas absorb them.
  4. *Relative-pose residual (O-01).* Variables `T_w_bi`, `T_w_bj` (right perturbation, `[rho, phi]`), measurement `Z = T_bi_bj_meas`. `r = Log(Z^-1 * T_w_bi^-1 * T_w_bj)` (same as GTSAM `BetweenFactor`). `J_r_xi_j = Jr^-1(r)`, `J_r_xi_i = -Jr^-1(r) * Ad(T_w_bj^-1 * T_w_bi)`. SE(3) `Jr(xi) = Jl(-xi)`, `Jl^-1(xi) = [Jl^-1(phi), -Jl^-1(phi) Q(rho, phi) Jl^-1(phi); 0, Jl^-1(phi)]` in `[rho, phi]` order, with `Q(rho, phi)` (Barfoot, State Estimation for Robotics, eq. 7.86) written out in full, plus the limits of its three coefficients for `theta < kSmallAngleQRad = 1e-3` rad (planner's call).
  5. *Non-holonomic residual (O-02).* Variables `T_w_b` (right perturbation) and `v_w_b` (additive); `omega_b_radps` and `T_b_o` are constants. `v_o = R_b_o^T (R_w_b^T v_w_b + omega_b x p_b_o)`, `r_nh = S v_o`, `S = [0 1 0; 0 0 1]` (lateral and vertical velocity of `o`, m/s). `J_rnh_xi = S R_b_o^T [0_3, skew(R_w_b^T v_w_b)]` (2x6), `J_rnh_v = S R_b_o^T R_w_b^T` (2x3), from `Exp(phi)^T u ~ u + skew(u) phi`.
  6. *Tests.* Map each formula to its test name (Tasks 2-5).

    EIGEN_MAKE_ALIGNED_OPERATOR_NEW

    EIGEN_MAKE_ALIGNED_OPERATOR_NEW

    Eigen::Matrix<double, 2, 6> J_r_xi = Eigen::Matrix<double, 2, 6>::Zero();  // right pert. T_w_b

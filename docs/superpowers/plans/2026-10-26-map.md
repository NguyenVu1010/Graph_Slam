# map: Voxel Hash Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fill in `mss::map::VoxelMap`, an iVox-style voxel hash map in frame `w` that keeps a ring of at most N points per voxel, runs kNN over the 27 surrounding voxels and prunes by radius. Add tests M-01 to M-03 and the mandatory no-allocation tests.

**Architecture:** One `.cpp` behind the frozen header. It holds a preallocated voxel pool (metadata, a flat `float` point array and a free-list) and an open-addressing, linear-probing hash table of voxel keys. Deletion uses backward shift, so there are no tombstones. The constructor sizes everything from `MapConfig`, and `insert`, `knn` and `prune` never allocate. Tests check the map against an independent brute-force reference model (a `std::map` of rings) in the test tree.

**Tech Stack:** C++17, Eigen 3.4, GoogleTest, CMake (`mss_add_test`), WSL build via `tools/wsl/build.sh`.

**Spec:** `core/map/include/mss/map/voxel_map.hpp` and `config.hpp` (frozen contract); `config/default.yaml` keys `map.*` (lines 59-65); `docs/Test_CI_CD.md` `### map — voxel hash map` (M-01..M-03); `docs/adr/007-voxel-hash-map.md`, `docs/adr/004-estimator-loosely-coupled-isam2.md`, plus ADR 003, 005, 006, 008, 009, 013; `docs/conventions.md`; `CLAUDE.md`.

## Design decisions (binding for all tasks)

Each item says where it comes from: (header), (ADR-007), or (planner's call).

- **Voxel key** (header): `key_a = floor(p_a / voxel_m)` on each axis. Compute it with `std::floor` on a division, not a multiply by the inverse, and store it as `std::int32_t`. (planner's call) If a `floor` value falls outside `[INT32_MIN + 1, INT32_MAX - 1]`:
  - `insert` skips the point and does not count it as dropped;
  - `knn` returns 0.

  This keeps `key ± 1` in range.
- **Point storage** (planner's call): points are stored as `float` x, y, z.
  - This bounds memory at 500000 x 20 x 12 B = 120 MB instead of 240 MB and halves cache traffic on the Pi5. The input is already `float` in `l`.
  - `insert` computes `p_w = T_w_l * p_l` in double, rounds it to float, promotes the rounded value back to double and computes the key from that. So every stored point lies inside its own voxel.
- **Ring** (header, ADR-007): a voxel holds `count <= N` points in slots `0..N-1`. A new point goes to slot `head`, then `head = (head + 1) % N` and `count = min(count + 1, N)`. "Slot order" in the tie rule means the slot index.
- **Hash table** (planner's call):
  - Capacity is the smallest power of two >= `2 * max_voxels`, so the load factor is at most 0.5.
  - A slot is `{int32 kx, ky, kz; uint32 voxel}`; `voxel == kEmptySlot` (`UINT32_MAX`) marks an empty slot.
  - Hash: `((uint32)kx * 73856093u) ^ ((uint32)ky * 19349669u) ^ ((uint32)kz * 83492791u)`, masked with `capacity - 1`.
  - Linear probing; deletion by backward shift (algorithm in Task 3).
- **Voxel pool** (planner's call):
  - Metadata: `max_voxels` entries of `{int32 kx, ky, kz; int32 count; int32 head; bool used}`.
  - Points: one `std::vector<float>` of `max_voxels * N * 3` floats. Point `s` of voxel `v` starts at index `((v * N) + s) * 3`.
  - Free pool indices: a `std::vector<std::uint32_t>` used as a stack (`free_top_`). It starts with every index, ordered so that index 0 is popped first.
- **Table full** (header): if a point needs a new voxel and `num_voxels() == max_voxels`, the point is dropped and `dropped_ += 1`. Points that go into existing voxels are still stored.
- **kNN distance** (planner's call):
  - Candidates are ranked by `d2 = dx*dx + dy*dy + dz*dz` in double, with `dx = double(stored_x) - p_w.x()`.
  - `out.dist2` stores `float(d2)`; `out.p_w[i]` is the stored float coordinates promoted to double.
  - Keep the top k by insertion into a fixed array with strict `<`, so earlier candidates win ties.
  - Visit order is `for dz in -1..1, for dy in -1..1, for dx in -1..1`, then slots `0..count-1` (the header's tie rule).
- **Prune** (header): remove a voxel when `||(key + 0.5) * voxel_m - p_w_b||^2 > prune_radius_m^2`. The comparison is strict, so a centre exactly at the radius is kept. Walk pool indices `0..max_voxels-1` where `used` is set, erase each removed voxel from the hash table and push its index on the free stack.

The tests do not pin down how a slot is deleted. Use backward-shift deletion (linear probing, no tombstones):
```
erase_slot(i):  // slots_[i] holds the key to remove
  j = i
  loop:
    j = (j + 1) & mask_
    if slots_[j].voxel == kEmptySlot: break
    h = home_slot(slots_[j])
    if ((j - h) & mask_) >= ((j - i) & mask_):   // home not in (i, j]
      slots_[i] = slots_[j]; i = j
  slots_[i].voxel = kEmptySlot
```
